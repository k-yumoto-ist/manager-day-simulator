# Manager's Day

20〜30名規模の組織を率いるマネージャーの1日を体験する、ブラウザ向けマネジメント・シミュレーションです。

## 起動

```powershell
npm install
npm run dev
```

表示されたローカルURLをPCブラウザで開いてください。

## 主な仕組み

- 9:00〜18:00と残業時間のゲーム内時計
- 45件の固定ベース・データ駆動チャットシナリオ
- リリース懸念、メンバー相談、顧客問い合わせ、営業相談などのイベントチェーン
- 8種類のチャット対応と、それぞれ異なる時間・信頼・成果への影響
- 適性と負荷を持つ3名への委任
- 参加、欠席、途中参加、途中退出、代理を選べる6つの会議
- 会議中の内職による集中低下と聞き逃しイベント
- 連続時間に応じて効率が上がる重要タスク作業
- 顧客信頼、チーム状態、事業成果、自分の余力、タスク進捗
- 退勤結果、マネジメントタイプ診断、重要な分岐点の振り返り

## データ拡張

`src/scenario.ts` の `scenarioEvents`、`meetings`、`initialTasks`、`delegates` を追加・編集することで、画面ロジックを変更せずにシナリオを拡張できます。
